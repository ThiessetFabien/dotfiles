# Dotfiles

Ce repository contient mes fichiers de configuration pour divers outils et environnements. Il est conçu pour sauvegarder et partager mes configurations, ainsi que pour faciliter la configuration de nouveaux environnements de travail.

## Ce que j'ai appris
- L'importance de la gestion des configurations pour la productivité.
- Comment mettre en place un environnement de développement cohérent sur plusieurs machines.
- Les avantages de l'utilisation de l'environnement de bureau i3 pour une gestion efficace des fenêtres comparé à d'autres environnements de bureau tels que Gnome ou KDE.
- La flexibilité et l'optimisation des flux de travail grâce à l'automatisation des tâches répétitives.
- L'importance de la documentation et des commentaires dans les fichiers de configuration pour faciliter la compréhension et la maintenance.
